# Women's CBB Picks (experimental)

NCAA Division I women's basketball spread and total picks from a machine-learning model, updated automatically on game days.

- **Picks:** https://assistjmd.github.io/wcbb-picks/
- **How it works and how it tested:** https://assistjmd.github.io/wcbb-picks/methodology.html

**Experimental, paper only.** The backtest shows a much bigger edge than is believable. Past women's lines came mostly from one soft book per game, and this season's closing lines show no edge yet. Picks are tracked as a test.

For fun, not financial advice.
